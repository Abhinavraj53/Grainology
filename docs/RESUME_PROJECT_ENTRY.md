# Resume-Ready Grainology Project Entry

## Project Title

**Grainology: Production Commodity Price Forecasting and MLOps Platform**

## One-Line Summary

Built an end-to-end agricultural intelligence platform that converts live Agmarknet and historical mandi data into national, state, and market-level 7/30/90-day commodity forecasts served through a React and Express application.

## Resume Bullets

- Engineered a forecasting pipeline over **205K+ daily price observations spanning 2001-2026**, generating Wheat, Paddy, Maize, and Mustard forecasts across national, state, and mandi views.
- Implemented leakage-safe temporal evaluation with horizon embargoes, train-only feature imputation, calibration/holdout separation, persistence baselines, temporal promotion gates, and split-conformal prediction intervals.
- Built a production MLOps workflow across **Agmarknet, Supabase, Kaggle, GitHub Actions, Node.js, and React**, with schema validation, SHA-256 checksums, drift reports, atomic release activation, and last-good forecast fallback.
- Developed geolocation-based nearest-mandi selection and farm-gate price estimates using Haversine distance and configurable transport/handling costs, while preserving state-level fallback behavior when mandi metadata is incomplete.

## Short Version

- Built and deployed a leakage-safe commodity forecasting and MLOps system over 205K+ observations, serving 7/30/90-day national, state, and nearest-mandi forecasts with calibrated intervals and farm-gate estimates.

## Technology Line

**Python, pandas, scikit-learn, CatBoost, LightGBM, XGBoost, Optuna, Supabase, Kaggle, GitHub Actions, Node.js, Express, React, TypeScript, Recharts**

## Interview Pitch

I owned the forecasting system from data ingestion to product delivery. The difficult part was not only fitting models; it was preventing time leakage, comparing against a persistence baseline, handling changing state and mandi coverage, publishing versioned artifacts safely, and keeping the website on the last valid release during retraining. I also added nearest-mandi and farm-gate estimates so the model output answered a farmer-facing business question rather than only producing a metric.
